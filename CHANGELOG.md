# Changelog

Release notes for the Vigil monorepo are maintained in each publishable package.

## Unreleased

- Added expandable/searchable JSON with JSON-path copying, advanced request filters, saved debug sessions with import/export, request/response comparison, and edit/replay.
- Added local Dio response mocks and network failure simulation.
- Added device-session identity and pending-call uploads, a desktop inspector with direct session connection, and session-scoped Express response controls.
- Added registered backend code failure points and request-linked diagnostics/logs.
- Refined Flutter/desktop branding, light palette, and independent inspector pane scrolling.
- Documented Git installation, frontend/backend setup, all four keys, SSM/deployment wiring, workflows, retention, and troubleshooting.

## 0.1.2

- Added masked multipart previews in the Dio inspector.
- Hardened body capture, backend uploads, and Node debug payloads.
- Added a Dio-to-Express integration check for capture, diagnostics, and ingest.

## 0.1.0

- Added Flutter request capture, Dio integration, and the in-app inspector.
- Added optional client-call upload to an HTTP ingest endpoint.
- Added Node trace, timing, gated diagnostics, and Express middleware packages.
