# Changelog

Release notes for the Vigil monorepo are maintained in each publishable package.

## 0.1.2

- Added masked multipart previews in the Dio inspector.
- Hardened body capture, backend uploads, and Node debug payloads.
- Added a Dio-to-Express integration check for capture, diagnostics, and ingest.

## 0.1.0

- Added Flutter request capture, Dio integration, and the in-app inspector.
- Added optional client-call upload to an HTTP ingest endpoint.
- Added Node trace, timing, gated diagnostics, and Express middleware packages.
